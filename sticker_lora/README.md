# 表情包 LoRA · 抽卡回收区

> 决策（2026-09-04）：表情包弃用米哈游 IP 素材（<godot_valley_demo 项目>/stickers 26 张 + <本机表情包素材目录> 1507 张仅作风格参考），
> 改走 **外部生成网站人工抽卡 → 本地微调角色 LoRA → 本地管线参考表情包量产**。

## 你要做的（抽卡）

1. 把选中的原图直接丢进 `raw/`——**文件名随意、可以有子目录**，支持 png/jpg/webp
2. 重复图不用挑，脚本按 sha256 自动去重

## 抽什么样的

| 项 | 要求 |
|---|---|
| 人设 | **同一角色同一套人设**（这是 LoRA 一致性的根本，混人设=废数据） |
| 构图 | 单主体大构图，表情占画面主体；背景干净或透明更佳 |
| 数量 | 首批 **≥60 张**（去重后），目标 100+ |
| 覆盖 | 尽量覆盖 22 个情绪词（见下），每类 3~5 张；不用凑满，脚本会报缺口 |
| 分辨率 | 短边 ≥512 最好；小图也能收（会规整放大，质量略降） |

**不要**：水印、多格拼图、大段文字、多人同框、画风突变。

22 个情绪词（与游戏内表情路由同一词表）：
开心大笑 / 微笑开心 / 生气发怒 / 委屈巴巴 / 大哭流泪 / 惊讶震惊 / 害羞脸红 / 疑惑不解 /
无语呆滞 / 坏笑偷笑 / 害怕发抖 / 得意得意 / 可爱卖萌 / 比心感谢 / 点赞加油 / 石化懵了 /
期待渴望 / 困倦睡觉 / 吃东西 / 敬礼认真 / 委屈生气 / 冷笑蔑视

## 丢完图跑这个

```powershell
# 在仓库根目录
python sticker_lora/prep_dataset.py --char 小灰
```

产物（`sticker_lora/dataset/`）：
- `images/000.png…` —— 规整后的方图训练集（主体裁方 + 统一尺寸）
- `captions.jsonl` —— 每图 caption（触发词 + 情绪标签，本地 Chinese-CLIP 自动打标）
- `contact_sheet.png` —— 缩略图快检表（人检：废图/人设漂了就删源图重跑）
- `manifest.json` —— 数量/置信度/情绪覆盖统计 + `ready` 判定

**就绪判据**：usable ≥60、高置信占比 >70%、情绪覆盖 ≥12/22 → `ready=true` 进微调。
缺口情绪按 manifest 的 `emotion_coverage` 定向补抽。
